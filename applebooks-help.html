1
百度网盘授权（一次性）
  1. 点击 EasyPub「苹果图书」页右侧「授权」按钮
  2. 浏览器自动打开百度 OAuth 授权页
  3. 登录百度账号 → 点击「授权」
  4. 页面会显示一段授权码，复制它
  5. 回到授权小窗口 → 粘贴授权码 → 点击「提交授权」
💡 授权码通常是一长串字符，复制时注意不要带空格或换行。
⚠️ 授权过程会启动 Chrome 浏览器，请确保本机已安装 Chrome 且 chromedriver.exe 版本匹配。
2
放入文件 + 上传到百度网盘
  1. 把 epub / txt / pdf 等图书文件拖入左侧放置框（或点击放置框选择）
  2. 文件会自动复制到 EasyPub 同目录的 download\
  3. 点击右侧「上传」按钮 → 程序调用 upload_folder_cmd.py，用 bypy syncup 增量同步
  4. 网盘目标路径：/我的应用数据/epub_download_backup
  5. 上传完成后按钮短暂显示「✓ 完成」
💡 bypy 是增量同步，重复上传不会重复占用空间。每次只放一个文件，需要上传多本时依次操作即可。
3
手机端：在百度网盘里找到文件
  1. iPhone / iPad 打开「百度网盘」App，登录同一个百度账号
  2. 底部导航点「文件」→ 看到「我的应用数据」分类
  3. 点进「我的应用数据」→ 找到 epub_download_backup 文件夹（这就是 EasyPub 上传的目标）
  4. 在文件夹里点开你想要的那本 epub → 系统会调用默认阅读器预览

图 2：我的应用数据 → epub_download_backup

4
导出到「图书」App（系统自带 Books）
  1. 文件在百度网盘预览界面打开后 → 点顶部的「更多」（···）按钮
  2. 在弹出的分享菜单里 → 找到「用图书打开」（Books 图标，蓝白橙色书）
  3. 点击后 → epub 自动添加到 iPhone / iPad 自带的「图书」App
  4. 打开系统「图书」App → 底部「图书馆」就能看到这本书
图 4：点「更多」→ 选「用图书打开」
⚠️ 如果分享菜单里没有「图书」图标：说明系统没把 Books 注册为接收 App。
解决：iPhone 设置 → 「图书」→ 打开「在共享表单中显示」开关 → 回网盘重新分享即可。
💡 epub 一旦导入「图书」App，会自动同步到所有登录同一 Apple ID 的设备（iPhone / iPad / Mac）。
✅ 整个流程：EasyPub 上传 → 百度网盘同步 → 手机点 epub → 选「图书」打开 → 在 iPhone 看书
